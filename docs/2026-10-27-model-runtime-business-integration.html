真实模型运行与业务回写

本地 Qwen3.5-4B 上传影像调用、adapter 审计元数据、超时边界和病例持久化验收

HTML 源文件：scripts/docs/.html-source/2026-10-27-model-runtime-business-integration.html

本页记录从业务病例到本地模型运行服务的真实跨进程联调。目标不是新增准确率证据，而是确认上传影像能够被受限模型服务读取，结构化结果能够进入持久任务与病例记录，并且失败时仍保持医生复核主链路。

运行边界

边界实现验证含义
影像路径后端按病例和影像 ID 生成绝对路径；模型运行服务只接受配置根目录内的文件。目录穿越、越界路径和未知格式均被拒绝。
Docker 共享卷case-uploads 共享卷以只读方式挂载到模型服务，后端与 worker 使用同一上传目录。解决容器内路径不存在或与宿主机路径不一致的问题。
内部服务鉴权配置 APP_INTERNAL_SERVICE_TOKEN 时，请求必须携带 X-Internal-Service-Token。模型服务不是匿名可调用的公开推理端点。
出站隐私病情和影像只允许进入回环或受控内网的项目自有模型服务；外部总结仅接收标签、置信度和受控证据。外部 API 不接收原始病例字段或影像路径。
模型输出只接受任务白名单中的结构化标签，固定要求医生复核，不生成最终诊断。模型是辅助判断分支，不替代临床复核。

持久化审计元数据

Qwen 分支成功时，病例分析的 runtime_metadata 保存模型名、adapter SHA256、服务端推理时延、生成时间、截断状态、峰值分配/保留显存和研究用途标记。这些字段供审计与运维排查；外部总结载荷继续使用字段白名单，不读取该元数据。

{
  "model": "Qwen3.5-4B",
  "adapter_sha256": "00ebeb2c...",
  "latency_ms": 2528,
  "truncated": false,
  "peak_allocated_gib": 3.242,
  "peak_reserved_gib": 3.311,
  "research_use_only": true
}

超时策略

后端默认 APP_PERCEPTION_TIMEOUT_SECONDS=90，覆盖本地首次模型加载与串行推理。热推理通常为数秒。超时会只把 Qwen 分支标记为 failed，病例继续进入确定性摘要和待复核，不会把未返回结果写成成功。

本轮首次 45 秒请求在模型冷加载后超时，业务回写仍保持完整且正确降级；提高默认上限并重启后，热推理跨进程验收成功。该调整只延长允许的等待时间，不改变模型、数据或临床结论。

测试覆盖

  • 后端 Qwen 契约覆盖结构化响应、受控病例字段、运行元数据解析和失败降级。
  • 模型运行服务测试覆盖结构化结果、越界影像拒绝、任务白名单、空影像、超时和非法模型输出。
  • 持久任务测试覆盖运行元数据保存、任务完成状态和病例待复核状态。
  • 外部边界测试继续拒绝把病例字段或影像发往第三方总结服务。

剩余限制

  • 真实模型输出置信度不可靠，不能用于阈值分诊；医生复核仍是强制边界。
  • Docker Compose 的共享卷与模型路径配置已修正，但本轮真实 GPU 联调使用本机进程与同一上传目录；完整容器部署仍需单独验收。
  • 运行服务缺少 causal_conv1d 和 flash-linear-attention 优化内核，目前使用可用的参考实现，热延迟为秒级。
  • 当前只完成一个影像任务的跨进程验收，不代表其他病种、外部数据或临床场景的泛化能力。
