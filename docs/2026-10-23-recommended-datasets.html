  3. OCT2017（7.85 GB，单 zip，建议晚间挂机）
  4. GitHub 两件：DeepDRiD（~2.8 GB）、EyeQ（~4 GB）
  5. 官方页三小件：STARE、HRF、DRISHTI-GS（合计 ~0.7 GB）

  1. Birdshot-WIDE：Zenodo 访问申请 + DUA（P2，但流程长建议现在发）
  2. 逐项归档许可文本到 datasets/licenses/，登记来源与版本号

四、磁盘与时间

  • 压缩包约 59 GB；解压后约 100-130 GB；加训练缓存建议预留 500 GB。
  • 目录约定：datasets/zip/ 存压缩包，datasets/extracted/<数据集名>/ 存解压内容，核验完成后可删 zip 省一半空间。
  • 按 50 Mbps 直连全程约 3 小时；OCT2017 单件建议用下载工具断点续传。

五、合规要点

  • CC BY 4.0（8 项）：署名引用原始论文即可；EyeQ（CC BY-NC-SA）与 DDR（NC）仅限非商用。
  • ODIR-5K 许可未明示：内部科研使用，公开成果前联系数据方；Other 类弱标签需关键词筛选。
  • 五分类 v2 与 Kaggle 镜像（爬取 + SMOTE）：仅限原型验证，禁入结论性训练与对外指标。
  • 竞赛条款集（IDRiD、APTOS）与挑战条款集仅限学术用途；JSIEC1000 版权归 JSIEC 并需引用原文。
  • figshare 项下载后核对条目许可并归档；即使数据已脱敏也不得尝试重新识别身份。
