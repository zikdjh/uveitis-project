24GB 显卡模型选型与部署资料

核验日期：2026-10-23 · 数据来源：HuggingFace API / GitHub API / 模型卡与 LICENSE 现场读取 · 项目：葡萄膜炎辅助诊断

一句话结论

首选：Cloudflare Clef-flash。 9.4B、Apache 2.0、多模态、Jev-compatible，是 24GB 单卡上质量与工程可用性最平衡的决策模型。

更稳的第二选择：Intern-Decision-4B。 Apache 2.0、多模态、显存压力更小，适合先跑通管线。

不要把 Jev 官方模型当开源模型。 Jev 是 TypeSafe AI 的托管 API，不是开放权重；开源部署要选 Clef、Intern-Decision、Kev、Tacit、d1 等。

24GB 部署预算

推荐可用预算
约 21-22 GB
4B 模型 FP16
约 8-11 GB
9B 模型 FP16
约 19-23 GB

粗算规则：

  • FP16 / BF16：参数量 × 2 字节 + 运行时与 KV/激活缓存。
  • 8-bit / Q8：参数量 × 1 字节 + 运行时与 KV/激活缓存。
  • 4-bit / Q4：参数量 × 0.5-0.6 字节 + 运行时与 KV/激活缓存。
  • Jev-like 模型通常没有长输出生成，KV 压力比聊天模型小，但长状态输入仍会占用显存。

结论：4B 级模型在 24GB 卡上最稳；9.4B 级模型 FP16 可试但偏紧，建议优先考虑 8-bit 或 Q4；27B 级模型不要用 FP16 直接部署。

Jev-like 决策模型候选

层级 模型 参数量 许可 模态 24GB 适配性 说明
P0 首选 Cloudflare Clef-flash 9.41B Apache 2.0 文本 / JSON / 图像 / 视频 可部署，偏紧 质量与功能上限最高，Jev-compatible。FP16 大约占 18-20GB 权重空间，24GB 卡可试，但更适合 8-bit / Q4 或短上下文。
P0 稳妥 Intern-Decision-4B 约 4B Apache 2.0 文本 / 图像 最稳 显存余量大，训练代码与推理后端齐全，适合作为第一套多模态决策管线。
P0 轻量 LiquidAI d1-3B 3.12B LFM Open License v1.0 文本 / 图像 很稳 支持中文，多模态，32k 上下文。许可可用但不是标准 OSI 开源，商用有年收入 1000 万美元限制。
P1 可训练 Kev-4B 4B 级 Apache 2.0 文本 很稳 基于 Qwen3.5-4B 的决策模型，适合用自己的标注数据训练。文本-only，显存压力小。
P1 精度 AnyJev Tacit-9B 9.4B Apache 2.0 文本 / 图像 可试，偏紧 单次前向决策，适合与 Clef-flash 做精度对照。FP16 部署建议控制在中等上下文。
P1 低资源 LiquidAI d1-omni-600M 0.587B LFM Open License v1.0 文本 / 图像 / 音频 极稳 适合端侧、低延迟、实时分诊和 API 冒烟测试；不是精度主力。
P2 兜底 GLiNER2.5-Decide 0.486B Apache 2.0 文本 极稳 适合做症状分类、简单路由、检查项抽取等确定性任务。

通用 LLM / MLLM 兜底层

Jev-like 模型负责低延迟、可阈值化的决策；复杂解释、RAG 推理和人工复核摘要可以交给通用 LLM。

建议部署路线

阶段 动作 说明
1. 冒烟 先部署 d1-omni-600M 或 Intern-Decision-0.8B 跑通 typed question → typed probability 的最小闭环，验证输入格式、JSON Schema 和前端展示。
2. 主链路 部署 Intern-Decision-4B 显存稳，Apache 2.0，支持图像，适合作为第一套可复现实验模型。
3. 精度对照 试部署 Clef-flash 先用短上下文和 8-bit / Q4 部署，确认能跑稳后再决定是否作为默认模型。
4. 自训练 用 Kev-4B 训练自己的决策头 适合接入项目自己的葡萄膜炎标注数据，尤其是解剖分型、急迫度、是否需要转诊等 typed tasks。
5. 医学基线 用 BioDecision v2 做评测 只做研究/评测，不进生产。

下一步清单

  • 确认 24GB 显卡是 RTX 3090 / 4090 还是工作站卡。
  • 先用 Intern-Decision-4B 或 d1-omni-600M 跑通 Jev-like 决策 API。
  • 确定诊断任务 Schema：noul、choice、score。
  • 准备小规模 typed decision 标注数据，优先覆盖解剖分型与红诊判断。
  • 再测试 Clef-flash 的 8-bit / Q4 部署与长上下文稳定性。
  • 把通用 LLM 兜底层与决策层分开跑，不要同时加载两个 9B 级模型。
