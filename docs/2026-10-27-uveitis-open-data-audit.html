葡萄膜炎开放数据审计

在用数据集许可、访问方式、患者级隔离能力与外部候选数据的核验结论

HTML 源文件：scripts/docs/.html-source/2026-10-27-uveitis-open-data-audit.html

核验日期：2026-10-27。访问方式：本地代理 http://127.0.0.1:7890，通过 Zenodo、Figshare、DataCite、Dryad、OSF、Harvard Dataverse、Kaggle 等平台官方 API 复核。本文记录首轮审计与代理恢复后的 R2 复检（12 个平台）两轮结果。

机器可读清单：model-training/datasets/audits/uveitis-open-data-audit-20261027.json；任务级审计：model-training/datasets/tasks/fundus_toxo_binary/audit.json。

1. 结论摘要

  • 本轮没有找到任何可直接下载、患者级隔离、且标签由医生确认的葡萄膜炎影像数据集。
  • 可直接下载、带医生标注的开放数据只有 ToxoFundus（眼弓形虫病眼底），但它没有患者 ID，只能做数据集内评估。
  • 新纳入两份开放临床数据（18 前葡萄膜炎角膜内皮、19 葡萄膜炎临床与病因表），并为 01 的 75 张 OCT 找到了计数吻合的临床对照表与 28 例医生确认病因。
  • 最接近"患者级 + 医生确认"的资源是 Birdshot-WIDE（Zenodo 受控访问，需 DUA），以及若干需联系作者/申请的数据（RV_CME_ML、UveAI、Stanford UWFFP）。
  • 在用数据集的许可并不统一：01/02/03/06/13/14/15/16/17 明确开放，04/05/07-12 存在许可不明或附加义务，生产使用前必须逐项复核。

4.1 R2 复检的三条线索落点

  • zenodo.13883485（Ocular Toxoplasmosis Fundus Images Dataset）经 API 核对就是本地 02_toxofundus：412 图 + 179 掩膜 + 标签表，CC BY 4.0、开放访问，可直接使用与再分发。
  • Scientific Data 论文 s41597-024-04113-2 的数据落点 figshare.26936446 就是本地 14_open_uwf700：700 图 / 602 患者、含 Uveitis 子目录、CC BY 4.0。其冻结测试集已在 2026-10-27 的运行中消费，禁止再用于调参或选型。
  • mendeley n9zp473wfw/2 就是本地 03_eye_five_class：作者自述图像来自 Google 搜图并用 SMOTE 平衡至每类 649 张，无患者 ID、无原始采集链路，只能定位为噪声预训练素材，不能作为独立验证。

4.2 R2 复检排除项

  • Roboflow Universe “Uveitis Dataset”：网络抓取、许可不明、无医生标注链路。
  • Kaggle kiran5566bs/keratitis-and-uveitis：许可为 unknown。
  • zenodo.23503796：葡萄膜炎 FFA 渗漏预测模型权重，CC BY-NC 4.0 且受控访问，是模型不是数据，只能作外部模型对照。

5. ToxoFundus 任务审计

脚本 model-training/scripts/datasets/audit_fundus_toxo_task.py 校验了"源标签 → 源图像 → 暂存图像 → 训练清单"的一致性：

  • 源标签 412 条、源图像 412 张、暂存图像 412 张完全一致，文件内容重复 0 组。
  • 唯一文件名差异 2809.jpg（标签）对 2805.jpg（图像）按唯一对应关系显式配对，不做静默匹配。
  • 原始标签分布：healthy 132、inactive 187、active 34、active/inactive 57、active/active 1、inactive/inactive 1；二分类任务为 healthy 对 toxoplasmosis。
  • 179 张掩膜中有 144 张能与图像按文件名主干匹配，可做分割辅助任务。
  • 数据集没有患者 ID，现有 train 330 / test 82 为图像级切分，外部验证结论被标记为 prohibited。

7. ToxoFundus 训练后冻结评估

审计后使用 ToxoFundus 训练行和 Open UWF 训练行完成一轮本地 QLoRA（run local-4060-uveitis-focus-20261027-01），训练 200/200 步，峰值保留显存 5.69 GiB，Modal 费用 $0.00。训练期间未读取 Toxo 测试行，也已排除 Open UWF 已消费的测试与验证行。

评估对象样本结果边界
内部选择验证14 条macro-F1 1.0，JSON 有效率 100%仅用于选择第 200 步 checkpoint，不足以证明泛化。
ToxoFundus 冻结测试82 条accuracy 0.914634，macro-F1 0.907345，JSON 有效率 100%图像级切分；数据集没有患者 ID，不能报告为患者级外部验证。

混淆情况：26 条 healthy 全部正确；49 条 toxoplasmosis 正确，7 条漏判为 healthy。该 adapter 适合作为弓形虫病辅助研究，不代表通用葡萄膜炎判断。测试结果已经冻结，不得用于继续调参。完整记录见 毒浆体病辅助训练与冻结评估。

8. 下一步

  • R2 复检确认公开渠道已穷尽：凡同时满足“患者级隔离 + 医生标注”的葡萄膜炎影像数据，目前不存在可直接下载的来源。后续如需推进，应转为 DUA / 合作申请，而不是继续公开检索。
  • ToxoFundus 仅作为毒浆体病（单一感染性葡萄膜炎亚型）辅助任务，不能替代通用葡萄膜炎外部验证。
  • 如需患者级外部验证，先获得负责人同意，再申请 Birdshot-WIDE 的 Zenodo 受控访问。
  • 逐项复核 04/05/07-12 的源站许可，并把许可文本归档到 model-training/datasets/licenses/。
  • 不得使用 Web 搜图、SMOTE 合成样本或非患者隔离数据冒充独立验证集。
