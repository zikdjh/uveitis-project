结论摘要

本冻结项记录 Qwen3.5-4B 的本地 QLoRA 第 20 步 adapter，作为葡萄膜炎辅助分析链路中的可选影像判断组件。它在同源 OCT 四类测试集上的 macro-F1 为 0.947245，高于第 100 步基线的 0.918252，提升为 +0.028993。该结果只说明候选在当前同源测评上优于基线，不构成临床验证、独立外部验证或诊断结论。

冻结状态是 研究用途候选。运行服务必须继续返回 requires_human_review=true，病例影像和病例文本不得发送到外部总结或网络搜索 API。

使用边界

  • 仅作为医生复核前的可选研究型第二意见，输出不得直接进入诊断、处方、处置或分诊自动化。
  • 当前任务只做 CNV、DME、DRUSEN、NORMAL 四类 OCT 辅助分类，不等同完整葡萄膜炎病因诊断，也不直接回答“是否为葡萄膜炎”。
  • 置信度未校准，运行烟测曾出现置信度 0 和空 impression；这些输出不能用于阈值判断或风险分层。
  • 病例文本和影像必须留在本地运行边界内。外部总结模型和网络搜索 API 只能接收脱敏、无影像的聚合问题，不得接收原始病例内容。
  • 在患者隔离外部验证、医生确认标签、亚组评价和设备泛化评价完成前，不得以临床产品或诊断系统名义发布。
