国外眼科数据集核验

国外开源免费眼科数据集的许可、规模和申请方式

一、核心结论

  1. 国外免费专病影像呈「小样本直下 + 一个大规模受限申请」格局：葡萄膜炎 OCT（75 文件）、 ToxoFundus（眼底+病灶 mask）、五分类含症状文本（v2）即时可用； Birdshot-WIDE（6,352 张超广角）是唯一大规模专病集，需签 DUA 申请，建议立即启动。
  2. 国外「图像 + 患者信息」多模态层的最佳免费项是 BRSET（巴西，PhysioNet open 状态已核验）， 16k+ 眼底带结构化患者元数据；OLIVES 与 AI-READI 免费但需人工走 gated / credentialed 流程。
  3. 骨干预训练与分割经典集全部免费可得：OCT2017、RFMiD 2.0、IDRiD、APTOS、Messidor、RETOUCH、DRIVE、STARE、DRISHTI-GS、HRF。
  4. 与国内清单互补：专病深度靠国际集，多模态形态贴近度靠国内 ODIR-5K / UWF-700， 两份清单合并即为完整数据规划。

三、核心专病层（葡萄膜炎相关）

3.1 葡萄膜炎 OCT（Mendeley hbr5pwk5w5 v1）

  • Universitas Indonesia，2023-04 发布；4 类：中间+后葡萄膜炎 / 全葡萄膜炎 / 正常 / RRD-PVR；共 7.22 MB，免登录直下；CC BY 4.0（当日页面核验）。
  • 用途：T1 OCT 细分类与 T3 专病微调的核心直用集；样本量小，只做微调/概念验证。
  • 链接：data.mendeley.com/datasets/hbr5pwk5w5/1

3.2 ToxoFundus（Zenodo 5156953 / 2024 版记录 13883485）

  • 巴拉圭亚松森两家医院采集；眼底图像 + 活动性/非活动性病灶分割 mask + labels CSV；眼弓形虫是感染性后葡萄膜炎的常见病因。
  • CC BY 4.0（API 核验 open）；Kaggle 存在同名镜像（TensorKitty，702 下载，当日核验）。
  • 用途：病灶分割头训练 + 感染性亚型外部验证。

3.3 五分类含症状文本（Mendeley n9zp473wfw v2，2024-12）

  • Daffodil International University（孟加拉）；Uveitis / Conjunctivitis / Cataract / Eyelid / Normal 五类图像，附每类症状文本描述；CC BY 4.0（当日页面核验）。
  • 红线：图像来自网络爬取且经 SMOTE 复制，仅限管线原型验证，禁入结论性训练与对外指标。

3.4 Birdshot-WIDE（Zenodo 19474623，Scientific Data 2026）

  • 巴黎 Cochin 医院 CO-BIRD 队列；5,042 张 BSCR 超广角眼底 + 1,310 张年龄/性别匹配对照；带纵向随访（中位 4.31 年）与患者元数据。
  • 受控访问：Zenodo 提交申请 → 签署 DUA → 审批下载；许可 CC BY 4.0（API 核验 restricted + cc-by-4.0）。
  • 价值：当前唯一大规模葡萄膜炎专用 UWF 集，适合微调与外部验证。建议立即启动申请。

3.5 其他专病相关工件（非数据集）

  • AS-OCT 葡萄膜炎 SUN 分级方法记录（Zenodo 7754367）：当日核验无文件，纯论文工件，仅方法参考。
  • 眼弓形虫 DL 系统综述工件（figshare 34179423，2026-10-07）：CC BY 4.0，2 文件；可作 RAG 证据，非训练数据。

四、多模态 + 患者信息层

  • BRSET（巴西 MOBI，PhysioNet v1.0.2）：16k+ 眼底彩照 + 结构化患者元数据（年龄、性别、糖尿病等），多标签疾病标注。 PhysioNet open 访问（当日 curl 核验标题与状态），免费注册后下载。 国外最贴合「图像 + 患者信息」形态的免费集，T3 预训练首选之一。
  • OLIVES（Clarkson 大学 iVIL 实验室）：OCTA + OCT + 临床文本，含血流/灌注标签；HuggingFace gated（API 401 确认），官方 GitHub 仓库本轮未定位成功；接受条款后免费。
  • AI-READI（美国 NIH 资助 STAND-UP 项目）：糖尿病相关并发症多设备多模态（眼底/OCT/OCTA/裂隙灯）+ 患者信息；免费但 credentialed（需完成培训并签协议）。PhysioNet 旧路径 /content/ai-readi/ 已 404，发布渠道调整中，需人工定位。
  • 佐证细节：figshare 上「Uveitis_All_2025_Oct」（5.1 GB，CC BY 4.0）描述含 "all cell types"，疑似组学而非影像；角膜内皮 AU 表格（76 KB，CC BY 4.0）可作前葡萄膜炎问卷字段参考。两者均已通过 figshare API（代理）核验。

五、预训练骨干层

  • OCT2017（UCSD，Mendeley rscbjbr9sj v3）：108,312 张 OCT，7.85 GB，CC BY 4.0（页面+许可当日核验）；OCT 骨干预训练。
  • RFMiD 2.0（意大利，Zenodo 7505822）：45 类长尾多病种眼底，CC BY 4.0（API 核验 open）；泛化评估与长尾预训练。
  • IDRiD（印度）：516 张眼底，DR 五级 + 4 类病灶像素级分割/检测；Grand Challenge 页面在架（当日核验），注册下载。
  • APTOS 2019（印度 APTOS 学会）：~3,662 训练眼底 DR 五级；Kaggle 竞赛页在架（当日核验），Late Submission 开放，账号即可取数。
  • EyePACS（美国）：~88k 眼底；本轮页面未渲染（待人工确认），该竞赛长期在架。
  • Messidor-1 / Messidor-2（法国 ADCIS）：1,200 / 1,748 张；ADCIS 页面在架（当日核验），接受使用协议后免费。
  • RETOUCH（多中心欧美）：OCT/OCTA 液体分割挑战；Grand Challenge 页面在架（当日核验），数据注册获取。
  • EyeQ（美国 EyePACS 图源、国内团队重标注）：28,792 张三级质量标注；GitHub 直下（前一轮核验）；CC BY-NC-SA；训练前质量过滤分支。

六、分割经典层（可解释性辅助）

  • DRIVE（荷兰）：40 张眼底血管分割基准；drive.grand-challenge.org 在架（当日核验）。
  • STARE（美国 UCSD/VA）：400 张 + 两套血管标注；Clemson 官方页在架（当日核验），直下。
  • DRISHTI-GS（印度 IIIT + Aravind）：101 张视盘/视杯分割；CVIT 官方页在架（当日核验）。
  • HRF（德国 FAU Erlangen）：45 张高分辨 + 血管标注；官方页在架（当日核验，旧站仍可用）。
  • RIM-ONE r3（西班牙）：视盘/视杯分割；原 miag-ull GitHub 仓库 404（API 核验），官方渠道需人工定位。
  • 候选未核验：CHASE_DB1（英国，申请制）、ORIGA（新加坡）、IOSTAR（欧洲）。

七、组学与背景资源（可选）

  • Uveitis Atlas（Zenodo 20783773）：眼内液 + 血 scRNA/TCR/BCR（病毒 vs 非感染性葡萄膜炎），CC BY 4.0，open（API 核验）；非影像，跨模态背景可选。
  • 葡萄膜炎 FFA 渗漏 RETFound 微调权重（Zenodo 23503796）：restricted + CC BY-NC 4.0（API 核验）；用 OCT/眼底预测 FFA 渗漏，可作 T1 迁移起点（非数据）。

八、行动顺序建议

  1. 零门槛直下：葡萄膜炎 OCT、ToxoFundus、五分类（限原型）、OCT2017、RFMiD 2.0。
  2. 免费注册：PhysioNet（取 BRSET）、Grand Challenge（IDRiD / RETOUCH / DRIVE）、Kaggle（APTOS / EyePACS / uveitis 镜像）、ADCIS（Messidor 协议）。
  3. 人工 / 代理走 gated：OLIVES（HF gated）、AI-READI（credentialed，渠道已变需定位）、RIM-ONE 官方渠道、figshare 相关条目（代理 API 已通，页面下载建议人工）。
  4. 立即启动申请：Birdshot-WIDE（Zenodo 提交访问申请 + 签 DUA），审批周期不定，越早越好。

九、合规要点

  • CC BY 4.0 的唯一义务是署名引用原始论文；转载/分发需保留许可声明。
  • NC 类（如 EyeQ 的 CC BY-NC-SA、FFA 权重的 CC BY-NC）仅限非商用科研。
  • restricted / gated / credentialed 集（Birdshot-WIDE、OLIVES、AI-READI、RETOUCH 部分）遵守各自 DUA，不得再分发。
  • 竞赛条款集（IDRiD、APTOS、EyePACS、RETOUCH）仅限学术用途，对外发布成果前核对条款。
  • 爬取 + SMOTE 来源（五分类 v2）只允许原型验证，不进入结论性训练集或对外指标。
  • 即使数据已脱敏，也不得尝试重新识别个人身份。

十、核验方法说明

  • API 级核验：Zenodo REST API（记录/许可/访问权）、figshare API（经代理，条目详情与搜索）、DataCite API、HuggingFace API（经代理）、GitHub REST API、PhysioNet 页面 curl。
  • 页面级核验：Mendeley 数据页、Kaggle 搜索与竞赛页、Grand Challenge 页（IDRiD/DRIVE/RETOUCH）、ADCIS、FAU、Clemson、IIIT CVIT、PhysioNet。
  • 代理说明：figshare 直连 403（反爬），经 127.0.0.1:7890 代理后 API 正常；HuggingFace 直连超时，走代理或镜像。
  • 环境限制记录：PhysioNet 网页在自动化浏览器下返回空，curl 可取；DataCite 部分查询瞬时失败；RIM-ONE / OLIVES 官方仓库地址未定位成功，均标注「待人工」。
  • 检索与核验脚本：仓库 scripts/research/intl-datasets-20261023/（round-01～08.mjs，ego-browser 环境，含 curl 代理调用）。
  • 数据集许可、可下载状态与字段可能随源站调整，正式使用前请以源站最新说明为准。
