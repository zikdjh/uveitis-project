模型评估与推理说明

本地评估、冻结测试、显存限制与推理边界

HTML 源文件：scripts/docs/.html-source/2026-10-26-model-runtime-evaluation.html

更新日期：2026-10-26

本页说明 Qwen3.5-4B 原型如何从训练产物进入本地评估，以及当前运行服务实际具备的能力边界。训练流程、基座、数据和 adapter 统一位于 model-training/；本目录只管理运行、评估和部署。

当前能力

  • model-runtime/app/ 提供基座目录、adapter 和运行配置的健康检查，不执行完整影像诊断。
  • model-runtime/code/local_qwen4b_eval.py 支持冻结测试集生成式评估、严格 JSON 解析、分任务指标、预测保存和中断续跑。
  • model-runtime/scripts/run_local_4060_eval.ps1 是 Windows 本地入口。
  • 运行侧只读取训练产物，不复制基座权重，也不修改训练记录。

当前没有训练或评估进程在运行，本次文档整理未启动 GPU，也未新增 Modal 费用。

运行资产

用途 路径
冻结评估基线 model-training/assets/qwen3.5-4b/local-4060-grouped-cont-20261025-01/best_adapter
OCT 候选 model-training/assets/qwen3.5-4b/local-4060-oct-focus-cont-20261025-01/best_adapter
冻结同集评估 model-training/assets/qwen3.5-4b/eval-oct-step20-vs-step100-20261025-01/

训练 manifest model-training/datasets/training/manifest.csv

第 20 步 OCT 候选已完成 1,000 条冻结测试评估，准确率 0.947，macro-F1 0.947245，严格 JSON 有效率 100%。第 100 步基线只完成 145/1,000 条，断点位于 eval-oct-step20-vs-step100-20261025-01/step100/predictions.partial.jsonl，必须保留并在后续续跑，不能用 145 条快照选型。

这些数字来自单一冻结测试集的原型评估，不是临床验证结论，也不代表跨医院、跨设备或患者独立队列上的泛化性能。

健康检查

从项目根目录启动模型运行服务：

cd model-runtime
..\backend\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8010

然后检查：

Invoke-RestMethod http://127.0.0.1:8010/health
Invoke-RestMethod http://127.0.0.1:8010/v1/models

ready 只表示基座和 adapter 文件可定位，degraded 表示路径缺失。/v1/models 返回感知模型、adapter 和补充决策模型的角色索引，不表示已完成影像推理或临床部署。

本地评估

先用一条样本验证评估路径：

.\model-runtime\scripts\run_local_4060_eval.ps1 `
  -AdapterDir 'model-training\assets\qwen3.5-4b\local-4060-grouped-cont-20261025-01\best_adapter' `
  -OutputDir 'model-training\assets\qwen3.5-4b\eval-layout-smoke-20261026' `
  -Tasks 'oct_aux_4class' -MaxSamples 1

续跑冻结基线时，输出目录必须指向原评估目录，且不要添加 -Overwrite：

powershell -NoProfile -ExecutionPolicy Bypass -File `
  'model-runtime\scripts\run_local_4060_eval.ps1' `
  -AdapterDir 'model-training\assets\qwen3.5-4b\local-4060-grouped-cont-20261025-01\best_adapter' `
  -OutputDir 'model-training\assets\qwen3.5-4b\eval-oct-step20-vs-step100-20261025-01\step100' `
  -Tasks 'oct_aux_4class'

评估器只读取冻结测试图像和 manifest 元数据，不参与训练、学习率调整或 checkpoint 选择。不要把测试结果回写训练标签。

本地硬件边界

RTX 4060 Laptop 8 GB 已完成 4-bit NF4 QLoRA 训练实测，正式训练峰值分配 5.45 GiB、峰值保留 5.69 GiB。训练配置限制为图像像素 65,536、最大序列 256、micro-batch 1、梯度累积 4。

评估显存峰值更低，但加载 4B 基座、adapter 和 processor 仍要求无其他大型 GPU 进程占用显存。评估期间应保持同一 GPU 不并行跑训练；出现 OOM 时先降低单次处理样本数，不要改测试清单。

输出约定

评估结果包含 eval_manifest.json、eval_metrics.json、eval_summary.json 和逐样本预测文件。中断时保留 .partial.jsonl，下一次从已有预测继续。正式结果必须保留 adapter 指纹、manifest 指纹、任务集合、样本数、运行耗时和显存峰值。

模型运行侧的临时结果放入 model-runtime/ 或 outputs/；需要长期保留的评估证据应归档到 model-training/assets/qwen3.5-4b/<run-id>/，并在训练产物索引中登记。

推理边界

当前模型是科研原型，只能输出辅助观察和结构化候选，不构成诊断、治疗或用药建议。接入业务链路前仍需完成：

  • 冻结测试集完整评估与错误分析。
  • 患者级或来源级独立验证。
  • 医生复核、拒答和升级规则。
  • API 输入脱敏、审计日志和模型版本锁定。

补充决策模型仍默认关闭。只有真实脱敏病例、医生确认标签、独立测试集和增益证据齐备后，才进入条件实验。
