国内眼科数据集核验

国内开源免费眼科数据集的许可、规模和可用性

HTML 源文件：scripts/docs/.html-source/2026-10-23-cn-eye-datasets.html

面向项目：葡萄膜炎辅助诊断智能系统（多模态训练数据规划）
核验日期：2026-10-23 · 性质：非商用科研用途 · 版本：v1.0
方法：当日对 iChallenge 官网、ODIR-2019 官方页、天池、飞桨 AI Studio、Kaggle、IEEE DataPort、 GitHub API、Nature/Scientific Data 文章页、DataCite API 逐个打开或调用确认； 不沿用历史调研结论。检索脚本见仓库 scripts/research/cn-datasets-20261023/（round-01～05.mjs）。

一、核心结论

  1. 国内目前没有免费开源的葡萄膜炎专病影像数据集。温州医科大学葡萄膜炎专病库为申请/交易制，不满足「开源免费」条件。
  2. 国内免费通用眼科数据量足以支撑「大规模预训练迁移 + 原型验证」：眼底万级（ODIR-5K、DDR、EDDFS 类）、OCT 十万级（OCT2017 镜像）、前节 OCT 4800 张（AGE）、OCTA 500 眼。
  3. 葡萄膜炎信号的免费来源 = ODIR-5K「Other」弱标签（关键词筛选）+ 新核验的 UWF-700 葡萄膜炎子集（100 张，含人口学信息）+ 医生端对照数据回流。

三、多模态底座（图像 + 患者信息，项目首选）

3.1 ODIR-5K

  • 内容：5,000 名患者 / 10,000 张双目眼底彩照；附年龄、性别、眼别与医生诊断关键词；8 类多标签（N/D/G/C/A/H/M/O）。
  • 葡萄膜炎用法：O 类（Other）弱标签，需用诊断关键词筛选，避免混入其他病种。
  • 渠道（当日全部验活）： ODIR-2019 官方页（Download Link） · Kaggle 镜像 · 天池 94998（免费，需账号；学生认证后免审批，文件清单已确认：训练包 1.09 GB、预处理包 376 MB、测试包 164 MB 等）。
  • 许可：官方未明示（Kaggle 标注 not specified）；内部科研使用惯例，公开成果前联系数据方确认。

3.2 Open UWF 700（Scientific Data 2024，含葡萄膜炎子集）

  • 内容：700 张高分辨超广角眼底 = DR / AMD / RVO / 病理性近视 / 葡萄膜炎（100 张） / 视网膜脱离 / 健康，各 100 张； 附诊断、年龄、性别、眼别（人口学表）与三位医生按视野/照明/伪影/对比度/总体的质量标注。
  • 价值：当前最贴合本项目「图像 + 患者信息」输入形态的国内免费集，可直接服务 T3 多模态原型。
  • 论文：s41597-024-04113-2；数据托管 figshare（本环境自动化访问 403，需人工浏览器下载，下载时核对条目许可）。

3.3 白内障细粒度集（Scientific Data 2026）

  • 机构：北京大学 + 华中科技大学。内容：白内障严重程度评分 + 临床诊断描述文本 + 眼底区域/视盘标注。
  • 价值：自带文本描述，可作「图像 + 结构化文字」弱配对样本，服务白内障鉴别分支。
  • 论文：s41597-026-06684-8；figshare 人工下载。

五、预训练与辅助数据集

5.1 病灶分割 / 质量 / 大规模眼底

  • DDR (OIA-DDR)：南开大学 + 北京同仁等；13,673 张眼底，DR 五级分类 + 4 类病灶分割 + 检测； GitHub README 内百度网盘直链（提取码 ue0t）+ Google Drive，当日确认在架；10 个分卷需先合并再解压；许可为非商用（NC）。
  • DeepDRiD：上海市第六人民医院；常规眼底 2,000 张 + UWF 256 张，DR 分级 + 图像质量评估； GitHub 直下；CC BY-SA 4.0（对外再分发衍生数据需同许可）。
  • EyeQ：国内团队在 EyePACS（美国图源）上重标注；28,792 张，Good/Usable/Reject 三级质量； GitHub 直下；CC BY-NC-SA。用途：训练前质量过滤分支。
  • LAG：北京同仁医院；11,760 张眼底（4,878 可疑 + 6,882 阴性），5,824 张含医生注意力区域标注； AG-CNN 仓库 Dropbox 第一部分 + 邮件索取解压密码（免费）；仅限学术，禁止再上传。

5.2 血管分割 / OCT / OCTA

  • FIVES：浙大二院；800 张 2048×2048 眼底 + 视网膜血管像素级标注，约 1.76 GB； 许可 CC BY 4.0（经 DataCite API 核验：DOI 10.6084/m9.figshare.19688169）；figshare 需人工下载。 用途：视网膜血管定量，服务血管炎特征分析。
  • OCTA-500：南京理工大学；500 眼 OCT + OCTA 三维数据（6×6 mm 与 3×3 mm），约 80 GB； IEEE DataPort 免费注册下载（页面已确认）。用途：OCTA 血管特征编码器。
  • AV 动静脉分割集：清华深研院 + 深圳市眼科；UWF 动静脉分割（Sci Data 2025-07， s41597-025-05381-2，figshare 人工下载）。
  • OCT2017（非国内图源，骨干预训练备选）：108,312 张 OCT，Mendeley 直下，CC BY 4.0。

5.3 细粒度 / 特殊模态 / 近期新集

  • JSIEC1000：汕头国际眼科中心（广东）；1,000 张眼底 / 39 类细粒度（母库 209,494 张）； Kaggle 镜像（ODbL，当日确认）；版权归 JSIEC， 引用 Nat Commun 2021。39 类覆盖多种眼底病，下载后需核对其中与葡萄膜炎/炎症相关的类别。
  • UWF 眼内肿瘤集：深圳市眼科医院（南方医科大）+ 澳门理工；6 类 UWF（脉络膜血管瘤、视网膜毛细血管瘤、脉络膜骨瘤等）； Sci Data 2025-08。价值：眼内肿瘤是葡萄膜炎的「伪装综合征」鉴别对象。
  • MultiEYE：香港中文大学；OCT 增强眼底疾病识别基准（IEEE TMI 2024）； GitHub（MIT），数据集挂 HuggingFace（本环境页面超时，README 已确认在架；国内建议走 hf-mirror.com 镜像）。
  • 其他 Sci Data 国内新集（均 figshare，按需取用）： 小儿 UWF 动静脉分割（南京医科大学，2026-09）、 ROP 智能筛查（深圳眼科，2024-05）、 COph100 婴儿眼底配准（RIDIRP）（南方科大，2025-01，figshare DOI 10.6084/m9.figshare.27061084）。
  • EyecareGPT 数据集：浙江大学（ACM MM 2025），中文眼科多模态；官方 README 标注 Coming Soon，建议持续关注 仓库。

六、文本与知识库（T2 / RAG，免费部分）

  • 葡萄膜炎临床字段规范：英国皇家眼科医师学会 Uveitis data set（2018，PDF 免费下载）—— 最小/扩展数据集规范，覆盖分型、活动性、并发症、治疗；用作病例 JSON Schema 与公开端问卷字段的对齐参照。 rcophth.ac.uk
  • 中文指南 / 共识：中华医学会眼科学分会葡萄膜炎相关共识与 MUV 多模态成像指南系列（2025–2026 多篇，文献库检索确认存在）； 经出版社 / 医脉通等渠道阅读，仅作 RAG 内部科研语料，注意版权。
  • 中文结构化病例：无现成开源集；按训练计划 SOP 由 LLM 生成 3,000–5,000 条 + 医学顾问审核。

七、元资源（继续找数据的入口）

  • Project-Imaging-X：1000+ 开放医学影像数据集综述（MIT）。
  • EyeDataHub：350+ 眼科数据集检索 / 引用 / 访问 CLI。
  • Awesome-Ophthalmology-Dataset、 Awesome-Medical-Dataset（openmedlab）。

八、行动顺序建议

  1. 零门槛直下（无需申请）：iChallenge 百度网盘直链、DDR 网盘、DeepDRiD、EyeQ、JSIEC1000（Kaggle）、ODIR-5K（Kaggle/天池）；LAG 发邮件要密码。
  2. 需人工浏览器：figshare 上的 Open UWF 700（含葡萄膜炎 100 张，最高优先）、白内障细粒度集、FIVES、AV 分割集、眼内肿瘤集、病理性近视结构集。
  3. 免费注册即可：OCTA-500（IEEE DataPort）、ODIR-2019（Grand Challenge）、REFUGE（Grand Challenge）。
  4. 下载后逐项归档许可文本；ODIR-5K 遵守「内部科研 + 成果公开前联系数据方」原则。

九、合规要点

  • 本清单仅覆盖非商用科研场景；NC 类许可（DDR、EyeQ 等）只允许非商用使用。
  • SA / ND 条款仅影响「再分发」：训练模型、发论文不受影响；对外发布预处理/衍生数据集时，CC BY-SA 需同许可发布，ND 禁止。
  • 未明示许可（ODIR-5K）：从官方渠道获取、注明出处、勿再分发原始数据；公开发布模型或商业化前书面确认。
  • JSIEC1000 版权归 JSIEC，按 Kaggle 页面条款使用并引用原始论文；LAG 仅学术、禁止再上传。
  • 即使数据已脱敏，也不得尝试重新识别个人身份。

十、核验方法说明

  • 页面级核验：iChallenge 官网、ODIR-2019 官方页、天池数据页、飞桨 AI Studio 数据页、Kaggle 数据页、IEEE DataPort 页、Nature 文章页当日逐个打开。
  • API 级核验：GitHub REST API（仓库 README、搜索）、DataCite API（figshare 条目许可与体积）、OpenAlex（国内机构 2024+ 眼科数据集论文普查）。
  • 环境限制记录：GitHub 网页与 HuggingFace 页面在核验时段无法直连（API 可用，HF 建议走镜像）；figshare 对自动化访问返回 403，相关条目标注「需人工浏览器」。
  • 检索与核验脚本：仓库 scripts/research/cn-datasets-20261023/（round-01～05.mjs，ego-browser 环境）。
  • 数据集许可、可下载状态与字段可能随源站调整，正式使用前请以源站最新说明为准。
