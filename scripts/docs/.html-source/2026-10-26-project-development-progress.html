结论摘要

项目已经从数据集调研和环境验证，进入“可演示业务链路、鉴权与权限体系、本地模型训练、界面和模型运行集成收口”阶段。工程交付综合估算约 72%，这是按可演示功能、集成程度和证据完整度做的排期估算，不是模型质量或临床验证结论。

当前最重要的收口路径是：先冻结文档和界面规范，再把模型运行 API 接入分析链路，同时完成冻结测试集基线评估。补充决策模型继续作为按门槛启动的方案，不占用 11.10 工程交付的关键路径。

11.10 工程验收标准

  1. 医生和管理员能够在各自角色范围内登录，访问控制由后端作为唯一授权边界，前端路由只负责界面控制。
  2. 访问令牌失效时能够无感刷新；并发请求不会重复刷新；退出、改密、停用账号和角色变更会撤销旧会话。
  3. 病例可以完成建档、影像上传、分析任务、结果查看和医生复核，异常状态有明确反馈。
  4. 知识文档可以写入、检索和查看索引状态；BGE-M3 与 zvec 使用同一向量空间。
  5. 模型运行服务能从固定路径读取基座和 adapter，返回结构化状态；接入分析任务后不把模型输出直接当作诊断。
  6. 训练侧完成基线与候选的同一冻结测试集比较，保留指标、清单哈希和 adapter 指纹；未达到门槛时不提升候选。
  7. 所有页面在桌面和移动端可操作，关键文本不重叠、不溢出，桌面和移动端构建均可复现。
  8. 文档明确标注非商用科研原型边界、数据限制和尚未完成的临床验证。
