跨来源特异性探针与外部验证边界

患者隔离的外部活动度数据不可获得后，改用从未训练的 ODIR-5K 正常眼底做跨来源假阳性读数

HTML 源文件：scripts/docs/.html-source/2026-10-27-cross-source-specificity.html

记录日期：2026-10-27。全部推理在本机 RTX 4060 Laptop 8 GB 上完成，未启动 Modal GPU，新增 Modal 费用为 $0.00。

背景：外部验证这条路已经关闭

活动度三分类的内部开发集已经消费掉，二分类测试集更早就已消费。继续提高可信度的常规做法是取得患者隔离、医生确认的活动度数据作为外部验证集，但这类数据无法获得。这意味着：

  • 不再等待外部活动度数据，也不再把它列为 11.10 前的待办事项。
  • “外部验证”这一结论在本项目中永久撤回，不是暂时挂起。
  • 任何以活动度或敏感性为核心的对外表述都不得使用；现有 adapter 只保留研究辅助定位。

但“没有外部阳性”并不等于“什么都测不了”。仍然可以做一件事：检查模型在另一个机构、另一种采集条件的正常眼底上会不会乱报阳性。这是特异性问题，只需要负样本，而这批负样本我们手上就有且从未用过。

为什么 ODIR-5K 可以用

数据源是 ODIR-5K（04_odir5k）。它在训练清单里存在，但任务 fundus_odir_multilabel 从未注册进 PHASE1_TASKS，因此这 2,000 行既没有参与过任何训练，也没有被任何评估读取过，像素是干净的。

项目结果说明
数据来源ODIR-5K，与 ToxoFundus、Open UWF、ZhangLab 均不同源CC BY 4.0
可用正常行946 张（标签 ['N']）来自 473 个患者组，每患者左右眼各一张
抽样方式按患者整组抽样 150 个患者，共 300 张固定种子 20261028；左右眼不会跨边界拆分
实际使用300 张全部写入 split=test，一次性读一次读完后这 300 行即为已消费
提示词与标签复用 fundus_toxo_binary 的 healthy 类不修改被评估 adapter 的任何推理配置

探针结果

被评估对象是冻结的弓形虫病二分类 adapter local-4060-uveitis-focus-20261027-01/best_adapter，SHA256 8d10d8a8…8be13，分辨率与训练一致（65,536 像素）。

这个数字说明什么

  • 同源冻结测试上这个 adapter 的 macro-F1 是 0.907，看起来已经很好；换到另一个机构的正常眼底，仍然有约 1/12 的图像被判成弓形虫病。
  • 误差方向集中在“正常被判成病灶”，也就是偏保守。对筛查类工具来说，这比漏掉病灶更容易被接受，但 8.33% 的假阳性会直接转化为医生复核负担。
  • 左右眼差异不大（6.67% 对 10.00%），没有出现明显的单眼系统性偏置；150 个患者里只有 1 人双眼同时被标记，说明误报更接近图像级噪声而非稳定的患者特征。
  • 与 Open UWF 的情况一致：验证集表现明显高于跨来源实测。这再次说明小规模同源验证会高估泛化能力。
  • 必须强调：这是一个特异性读数，不是敏感度读数，因为没有外部阳性样本；它不能用来支持“能识别活动性葡萄膜炎”之类的结论。

边界与不可宣称项

  • ODIR 的 N 表示八类目标疾病缺失，不等于“完全无病变的正常眼”，因此 8.33% 是保守上界还是乐观估计无法从本探针判定。
  • 读数按图像统计；虽然抽样按患者整组进行，但不能表述为患者隔离验证。
  • 这 300 行已经消费，不得用于调参、选择 checkpoint 或提示词，也不得再次报告为新的独立读数。
  • 本项目不存在可用的外部活动度阳性集，因此活动度敏感性、活动期判别准确率等指标一律不报告。

后续

  1. 训练侧到此为止：在取得真实病例之前，继续训练既没有合法度量目标，也不会产生新的可信结论。
  2. 把“活动度外部验证不可获得”作为已接受的限制写进交付说明，而不是待办事项。
  3. 若系统后续进入实际使用，唯一可获得真实独立证据的方式是在运行链路中做静默取证：把模型输出与医生最终确认结论并排记录，逐步积累评价集，并在取得授权后使用。
  4. 运行链路继续按既定设计：微调判断、决策模型、RAG 与网络检索均为可选分支，不可用时跳过且不阻断主链路；所有输出保留医生复核。
