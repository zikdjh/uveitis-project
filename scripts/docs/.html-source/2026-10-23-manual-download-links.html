用途：人工浏览器逐项下载，避免脚本/直链被挡。
整理日期：2026-10-23 · 版本：v1.0
本轮口径：全部条目均按待重新下载处理（上一轮已下载文件已清理）。
建议保存位置：model-training/datasets/p0/<数据集名>/ 或 model-training/datasets/p1/<数据集名>/
用法：先点“条目页 / 界面”，在页面上找对应的下载按钮。不要直接右键另存为 ndownloader 链接， 有些站会校验来源或要求登录。
figshare：如果条目页被重定向到 springernature.figshare.com，只要页面能打开，仍然用页面上的 Download all 即可。
