AgentScope 工具链编排

决策模型训练暂缓期间的调用链占位、AgentScope 规划流程、可用性门控与降级规则

HTML 源文件：scripts/docs/.html-source/2026-10-27-agent-toolchain-plan.html

辅助分析链路由若干可选能力组成。当前真实可用的是 Qwen 微调判断、RAG 向量检索、网络搜索和外部 API 总结；补充决策模型本轮暂缓训练，但它在调用链中的槽位保留，由后端标记为“跳过”，不占用额度、不影响主链路。链路的编排选择交给 AgentScope 规划，执行仍由后端按确定性顺序完成。

调用链定义

顺序技能键可用性门控产物
1qwen_judgmentAPP_MODEL_MODE=remote、APP_QWEN_JUDGMENT_ENABLED=true 且已配置感知服务地址。findings、impression、confidence
2retrievalAPP_RAG_ENABLED=true 且本地知识索引存在文档。evidence
3decisionAPP_DECISION_ENABLED=true 且已配置决策服务地址。本轮暂缓训练，默认关闭。differential、urgency
4web_search管理员在服务配置页启用网络搜索。web_evidence
5external_summary管理员已配置外部总结接口与密钥。summary、recommendations

技能清单、顺序和可用性原因由 backend/app/agents/toolchain.py 统一声明，后端与规划器共用同一份定义，避免两处描述漂移。

规划与执行流程

  1. 后端计算每个技能的可用性与不可用原因，生成技能目录。
  2. AgentScope 规划代理通过只读工具 list_toolchain_options 读取技能目录。
  3. 规划代理用结构化输出返回 steps 与一段 rationale。
  4. 后端规范化该提案：丢弃未登记技能、剔除不可用技能、补回必需技能，并按调用链顺序排序。
  5. 后端按计划逐个执行技能；未进入计划的技能标记为跳过并记录原因。
  6. 安全校验与报告整理始终执行，不受规划结果影响。

规划代理只决定“跑哪些”，不直接调用外部接口，因此不会出现同一次病例分析被模型重复调用付费 API 的情况；执行顺序、超时和失败处理仍由后端确定性代码控制。

决策模型槽位策略

  • 技能表中保留 decision 条目，并标记 deferred=true。
  • 运行时 APP_DECISION_ENABLED=false，可用性原因固定为“补充决策模型训练暂缓，槽位保留但未启用”。
  • 病例结果中的 component_results 保留该组件，状态为 skipped，便于界面和审计看到槽位位置。
  • 训练数据、医生确认标签和冻结测试集齐备前，不启动决策模型训练，也不使用弱标签或合成标签给出“已验证”结论。

可配置项

环境变量默认值说明
APP_AGENT_ORCHESTRATION_ENABLEDfalse是否启用 AgentScope 工具链规划。关闭时使用确定性顺序。
APP_AGENT_PLANNER_PROTOCOLopenai_chat_completions规划模型协议，可选 openai_responses、anthropic_messages。
APP_AGENT_PLANNER_BASE_URL / MODEL / API_KEY空规划模型专用地址、模型名和密钥。
APP_AGENT_PLANNER_USE_SUMMARY_CREDENTIALStrue专用配置为空时复用管理员维护的外部总结接口凭据，避免重复配置。
APP_AGENT_PLANNER_MAX_STEPS6规划代理的最大推理轮数上限。
APP_AGENT_PLANNER_TIMEOUT_SECONDS30单次规划的超时时间，超时即回退确定性顺序。

依赖与安装

AgentScope 以可选依赖形式接入，不进入默认安装路径：

uv sync --extra agent

  • 锁定版本为 agentscope==2.0.11（Python 3.11+）。
  • AgentScope 的 mcp 依赖要求 pydantic>=2.12.0，后端 pydantic 已从 2.10.6 升级到 2.12.5，其余固定版本不变。
  • 升级后后端测试套件与前端构建均通过。
  • 未安装 AgentScope 时，规划器检测失败后直接使用确定性顺序，不产生运行时错误。

降级与安全边界

情形行为
未启用工具链规划按可用性执行全部已配置技能，规划阶段标注“确定性兜底规划”。
未安装 AgentScope同上，并在规划说明中记录“未安装 AgentScope”。
规划模型凭据不完整同上，不发起外部调用。
规划超时或返回异常回退确定性顺序，病例分析继续完成，异常原因写入规划阶段说明。
规划结果包含不可用技能后端剔除该技能并记录原因，绝不因为规划结果绕过可用性门控。
病例与影像外发规划请求只包含技能目录和选择规则，不包含病例字段、影像字段或“有无影像”提示。外部总结与网络搜索同样走字段白名单和硬校验；所有 httpx 出站请求还经过统一请求钩子，公开主机携带病例或影像字段时直接拦截，项目自有模型端点也必须位于 localhost、私网或受控域名。

所有分支失败均不阻断医生复核链路。结果中的 safety_flags 会在未使用模型规划时追加“工具链由确定性规则编排，未使用模型规划”。
