R-04 本轮发现

  • 总结 API 出现一次失败后复测成功的现象：首次返回 ok:false（外部模型返回空响应），随后复测返回 ok:true。当前 anthropic_messages + deepseek-flash 配置可用，首次失败疑为瞬时故障或配置保存后未即时生效；建议连通性测试在失败时自动重试一次再判定。
  • 搜索 API 开关为 true，但 8 家服务商均无凭据，批量测试不产生任何外部检索结果。功能符合不可用即跳过、不阻断主链路的设计，但在补齐密钥前搜索阶段实际为空转。
  • 外部总结与搜索不可用时，分析主链路仍全阶段完成并进入待复核，降级不阻断主链路的设计得到验证。
