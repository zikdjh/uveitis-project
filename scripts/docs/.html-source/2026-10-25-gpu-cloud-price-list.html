计价与采购口径

比较成本时，先确认是否包含目标配置和存储。

  1. 01
    30 天按 720 小时折算 用于固定月租横向比较。官网同时给小时价与包月价时，两个价格分别展示。
  2. 02
    AWS 月费包含 80GiB EBS 按 gp3 每 GiB 每月 0.10 美元估算，80GiB 为 8 美元/月；公网出流量、快照和税费另计。
  3. 03
    RunPod 月费包含 80GB 存储 存储按每 GiB 每月 0.10 美元估算，80GiB 为 8 美元/月；镜像缓存和出网流量另计。
  4. 04
    AutoDL 只作卡价参考 ¥1.88/小时和 ¥1.32/小时均为 GPU 小时价，不能直接当作满足 8 核、32GB、80GB 的整机总价。
  5. 05
    签约前确认库存、含税专票与关机规则 同时核对持久盘、快照、数据保留、公网流量、SLA、退款条件和续费价格。
